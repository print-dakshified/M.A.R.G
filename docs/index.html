What is M.A.R.G.?

M.A.R.G. stands for Multilingual Assistance and Resource Guide. We are making digital government services easier to understand and access.

Our mission

To reduce the confusion people face while filling out government forms by providing accessible, multilingual, AI-powered guidance directly in their browser.

Get started in minutes.

Install the extension manually in Chrome using these steps.

01

Download the extension

Download the M.A.R.G. ZIP package from the button below and extract it.

02

Open Chrome Extensions

Visit chrome://extensions in your Chrome browser.

03

Enable Developer Mode

Switch on Developer mode in the top-right corner.

04

Load the extension

Click Load unpacked and select the extracted extension dist folder.
