GETTING STARTED

Up and running in minutes.

Install M.A.R.G. in Chrome using Developer Mode.

01

Download M.A.R.G.

Download the extension ZIP and extract it on your computer.

02

Open Chrome Extensions

Visit chrome://extensions in your Chrome browser.

03

Enable Developer Mode

Turn on Developer Mode in the top-right corner.

04

Load unpacked

Click Load unpacked and select the extracted extension dist folder.

GOT QUESTIONS?

Frequently asked questions.

What is M.A.R.G.? +
M.A.R.G. is a multilingual AI-powered Chrome extension designed to help people understand and navigate Indian government forms.
Is M.A.R.G. free? +
The extension is distributed as a free project. Its online AI services depend on the availability and usage limits of the backend and AI providers.
How do I install it? +
Download and extract the ZIP, open chrome://extensions, enable Developer Mode, and select Load unpacked. Choose the extracted dist folder.
Does it support Indian languages? +
M.A.R.G. is designed for multilingual conversations, with language support depending on the speech and language services used.
Does it automatically submit government forms? +
M.A.R.G. is an assistance tool. Always review your information and submit forms yourself through the official government website.
